# Track Manager — public web experience

[Open Track Manager](https://kimdohong.github.io/track-manager-web/)

Compiled Flutter distribution only. Select a synthetic demonstration track, replay positions through the shared lap engine, and save/reopen lap results in your browser.

All routes and positions are generated examples, not captured driving data. This stage does not collect live GPS/OBD data, provide spectator streaming, or synchronize records between devices.

Records stay in this browser; clearing site data removes them. Third-party notices are included in assets/NOTICES.
