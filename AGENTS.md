# Public distribution repository

This repository stores built Flutter web assets, not the development source. Read [CLOUD_DEVELOPMENT.md](CLOUD_DEVELOPMENT.md) before editing.

- Feature implementation belongs in the authorized private Track Manager source repository, using its existing web entrypoint and domain code.
- Do not create a second app here or patch generated JavaScript to implement features.
- Keep deployment metadata and these documentation files when replacing reviewed build output.
- Never publish private source, source maps, personal records or credentials.
- A documentation-only change must not be described as a new application release.
